# 🎬 Stremio  Installer & RE-SIGNER  (macOS)

أداة بسيطة لتثبيت **Stremio** أو **Stremio Horizon** على macOS  
مع حل مشاكل التوقيع و **Gatekeeper** تلقائيًا.

---

## 🚀 البداية 

### 1️⃣ افتح التيرمنال
- اضغط `⌘ + Space`
- اكتب `Terminal` ثم افتحه

### 2️⃣ شغّل الأداة
انسخ الأمر التالي والصقه في التيرمنال ثم اضغط Enter:

```bash
curl -fsSL https://raw.githubusercontent.com/3-pr/fix-stremio/refs/heads/main/stremioinstaller.sh | bash
```

---

## ⚙️ الخيارات داخل الأداة

عند التشغيل بتطلع لك خيارات بسيطة:

### الخيار (1) — تثبيت تلقائي
- الأداة تحمّل Stremio تلقائيًا
- تركّب التطبيق
- تحل مشكلة التوقيع
- تشغّل التطبيق مباشرة

### الخيار (2) — عندك ملف DMG جاهز
- تستخدم ملف DMG موجود عندك
- تسحب الملف للتيرمنال
- والأداة تكمل الباقي

## ✅ ملاحظات سريعة
- قد يُطلب منك إدخال كلمة مرور الجهاز (sudo) أثناء التثبيت
- الأداة تحذف أي نسخة قديمة وتثبت نسخة نظيفة
- لا تحتاج تدخل يدوي في إعدادات الأمان
